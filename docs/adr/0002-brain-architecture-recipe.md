# ADR-0002 · 神经网络配方与档次承诺

- **状态**：已采纳
- **日期**:2026-05-18
- **背景**：在多种神经网络机制中需要选定一个"配方"作为整个项目的大脑设计目标，并明确每个机制的成功概率，避免画饼。

---

## 决策

### 神经网络配方

```
NEAT 拓扑进化     —— 大脑结构会自己长，不写死
+ CTRNN 递归       —— 个体有"现在的状态"和节律
+ 神经调节         —— 调节神经元改变其它神经元行为，进化"情绪"
+ 内在动机         —— 好奇心驱动，破死亡螺旋
+ 通信信号场       —— 个体可发信号到地图，可读取邻近信号
+ 拉马克开关       —— 终身学习成果可选传子代
```

### 档次承诺（绝对不画饼）

#### 🟢 高确定性（90%+）—— 答辩底线
- NEAT 拓扑进化与可视化
- 趋食、避障、探索行为
- 物种树清晰分支
- 真实 2.5D 地形上的群体密度差异
- 行为热力图、适应度曲线
- 内在动机驱动的早期探索扩散

> 这一档来自数十年成熟先例（NEAT 1990s、Sakana AI 2024、Pathak 2017），几乎不会失败。

#### 🟡 中等确定性（50-70%）—— 加分项
- CTRNN 节律行为（巡逻、张望、踱步）
- 神经调节"情绪可见"（同一个体在不同情境下行为差异显著）
- 三种地理分化生态位（山洞群居 / 山顶侦察 / 平原游牧）
- 简单信号收发（不一定有语义）
- 拉马克 vs 达尔文对照差异

> 需要奖励设计 + 调参运气，每个机制都做了**降级方案**保兜底。

#### 🔴 低确定性（10-30%）—— SSR 彩蛋
- 信号涌现"语义"（信号 A ≈ 食物方向）
- 围猎合作
- 信号引诱 / 欺骗
- 工具使用 / 物体堆叠

> NeurIPS 论文级别难题，OpenAI 用了几千 GPU 几个月才做出。
> **算力差距 4-5 个数量级**，课设规模"漂亮版本"概率低。
> 跑出来吹爆，跑不出不影响答辩。

---

## 为什么选这个配方

### 配方层级递进

| 层 | 增量价值 | 成本 |
|---|---|---|
| 纯 NEAT | 行为基础进化 | 低 |
| + CTRNN | 个体有"持续状态"，从金鱼变活物 | 几乎免费（NEAT 允许递归边） |
| + 神经调节 | 同网络情境敏感，看起来像有情绪 | 中（给某些神经元打调节标签） |
| + 内在动机 | 解决稀疏奖励死亡螺旋 | 中（多一个预测头 + 内部 reward 通道） |
| + 通信 | 让 F-COMM 模块成为可能 | 中（信号场是 IWorldLayer） |
| + 拉马克开关 | 哲学对比实验 | 低（运行时开关） |

每一步增量都有明确价值且成本可控。**不是把所有时髦的东西堆上去，是经过取舍的最小有效组合**。

### 主动放弃的机制

- **HyperNEAT**：复杂度高，对课设过度
- **Spiking 神经网络**：训练麻烦，工程投入回报不成正比
- **完整模块化大脑**：调试地狱
- **身体形态进化**：偏离 OOP 课设主题
- **进化可塑性规则**：科研价值大，工程稳定性差

---

## 渐进添加策略

**不是 M0 就把所有机制都做齐**。配方按基线和模块拆分：

| 机制 | 加入时机 | 在哪个阶段/模块 |
|---|---|---|
| NEAT 拓扑 | 基线 M3 | `core/brain/neat/` |
| CTRNN 递归 | 基线 M3（NEAT 允许递归边） | 同上 |
| 内在动机 | 基线 M1（防早期死亡螺旋） | `core/reward/intrinsic/` |
| 通信信号场 | 模块 F-COMM | `core/world/signal_layer/` |
| 神经调节 | 模块 F-NEUROMOD | NEAT 的 marker 扩展 |
| 拉马克开关 | 模块 F-LEARN | `core/evolution/lamarck/` |

每个机制必须等"前一步完美完成"才加。**完美的标准在各阶段/模块文档里给出**。

---

## 影响

- M0 接口设计必须能容纳"递归连接"和"调节神经元"——`IBrain` 不能假设网络是前馈的
- 内在动机奖励和外部奖励都通过 `IRewardComponent` 接入
- 通信能力是 `IAgentCapability`（发信号）+ `IPerception`（读信号）
- 调节标签写在 `Genome` 元数据里，由 NEAT 变异时附加

---

## 兜底承诺

每个 🟡 和 🔴 档机制的 module 卡片都包含：
- **完美版**：理想效果
- **标准版**：实际可期待的
- **降级版**：跑不出来时怎么挽救（往往是改成"过程可视化"，让没涌现的现象至少在 UI 上还有看头）

详见 `docs/modules/` 下各卡片。
