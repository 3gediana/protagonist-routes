# 涌现行为目标清单

> 这份文档列出当前系统**尚未实现但有可能涌现**的复杂行为。
> 每个行为只保留文献资料，不包含"为什么缺失"或"需要什么条件"。
>
> 本文档基于大规模学术文献调研编写，涵盖：Miikkulainen Lab NEAT 研究、Sakana AI、Avida 数字进化平台、OpenAI Hide & Seek、JaxLife、POET、PMC/IEEE/Nature/eLife/AAAI/ICLR 论文等。
> 重点关注**最大条件**——当环境、奖励、感知、网络容量都足够丰富时，能涌现到什么程度。
>
> **最后更新**：2026-05-19（代码实时进度：Pathogen NN + 抗原漂移已实现并验证）

## 一、原始语言涌现

### 文献资料

| 来源 | 关键发现 |
|---|---|
| Rawal & Miikkulainen (ALIFE 2014) | 通信通过"垫脚石"渐进演化——先演化配偶选择，再演化狩猎通信。如果个体能直接感知目标，通信不会演化 |
| Mordatch & Abbeel (AAAI 2018) | 在物理环境中，通过联合奖励 + 多轮交互 + 词汇表约束，涌现出有词汇和语法的组合语言。Agent 自发形成概念并分配任意符号。当通信不可用时，还涌现出非语言通信（指向、引导） |
| Lazaridou et al. (ICLR 2017) | 在 referential game 中，通过合作任务 + 离散消息空间，涌现出类似自然语言的通信协议 |
| CMU Thesis (2023) | 涌现通信通常发送"压缩不足的消息"，需要信息瓶颈来迫使消息精简和语义化 |
| ECOCURL Project (ANR 2020-2026) | 内在动机驱动的多 agent 学习中，组合通信系统可以支持开放式合作技能发现 |
| JaxLife (2024) | 在 256 agent 的开放世界模拟中，涌现出原始通信协议、农业和工具使用。但 256 agent 时通信显著性接近零——agent 太多时，随机噪声淹没了信号 |
| Sukhbaatar et al. (2016) / Foerster et al. (2016) | 神经网络可以在没有预编码协议的情况下演化通信，但需要任务驱动——通信本身不是目标，完成任务才是 |

## 二、围猎涌现

### 文献资料

| 来源 | 关键发现 |
|---|---|
| Miikkulainen Lab (WCCI 2012) | 鬣狗围攻狮子通过垫脚石出现：冒险者 → 安全距离 → 同时攻击 → 围攻。关键：猎物必须足够难抓且回报足够高 |
| eLife (2023) | 多捕食者协作成功率增长远超独立假设的理论预测，说明出现了质的不同的狩猎策略。前提是猎物逃脱速度接近捕食者 |
| Li et al. (New J. Phys. 2023) | 仅靠生存压力（猎物被抓 -1，捕食者抓到 +1）就能涌现猎物的集群行为和捕食者的分散/混淆策略 |
| **OpenAI Hide & Seek (ICLR 2020)** | 通过多 agent 竞争 + 简单游戏规则 + 标准 RL，涌现出 6 个阶段的策略和反策略：(1) 追逐/躲避 → (2) 建造堡垒 → (3) 使用斜坡翻越 → (4) 封锁斜坡 → (5) 使用箱子搭桥 → (6) 分工合作。关键：环境必须足够复杂（有可移动物体、斜坡、barricades），竞争必须持续足够久（数亿局） |
| MIT CSAIL (CoEvolution Report) | 3 个捕食者可以围捕猎物，但策略对团队成员变化敏感——加/减一个成员会导致策略失效 |
| Nolfi & Floreano (1998) | 捕食者和猎物的军备竞赛导致双方能力持续提升。即使适应度值停滞，实际能力也在进化（"Master Tournament"测试揭示） |

## 三、社交距离涌现

### 文献资料

| 来源 | 关键发现 |
|---|---|
| PMC (2022) - 疾病回避进化理论 | 疾病回避是进化上高度保守的机制。因为假阴性（没避开感染者）的代价是致命的，所以回避机制倾向于过度泛化——避开所有"看起来不正常"的个体 |
| Penley et al. (C. elegans 实验) | 回避行为在没有可测量的适应度代价的情况下演化出来，且在寄生虫消失后仍长期维持 |
| Curtis (2014) / Klemme & Karvonen (2017) | 回避通常被描述为"廉价的替代方案"——比抗性（resistance）成本低得多 |
| Epstein et al. (2008) - 埃博拉模型 | 如果个体在爆发时选择逃离，反而可能加速疾病传播。回避行为的效果取决于空间结构 |

## 四、建筑涌现

### 文献资料

| 来源 | 关键发现 |
|---|---|
| Odling-Smee et al. (Niche Construction Theory) | 生态位构建是两个表型的组合：修改环境（ΔE）+ 对修改的适应（ΔF(ΔE))。存在鸡和蛋的问题：环境修改和适应哪个先出现？ |
| Callahan et al. (Stanford, 微生物实验) | 适应性生态位构建快速且可重复地演化出来。早期构建者的关键特征：在祖先修改的环境中适应度极低，但在自己修改的环境中适应度极高 |
| Avida (Lenski et al., Nature 2003) | 通过奖励中间步骤（8 个简单逻辑函数），数字生物演化出了 EQU（逻辑等于）——需要 19 条协调指令的复杂功能。关键发现：演化路径不总是向上爬升，有时需要先走下坡路（某些突变使适应度减半，但为后续 EQU 的出现铺平了道路） |
| **OpenAI Hide & Seek (ICLR 2020)** | hiders 学会用箱子建造多物体堡垒，seekers 学会用斜坡翻越。关键：环境必须有可移动物体 + 物理交互 + 竞争压力 |
| JaxLife (2024) | 在开放世界模拟中，涌现出大规模地形改造和协调行动。agent 通过 terraforming 行动改变地形，创造出对自身有利的空间布局 |
| Sakana AI - PD-NCA (2025) | 神经细胞自动机中，多个物种通过攻击/防御向量竞争领地，自发出现"贴墙生长"行为——利用墙壁作为可防御的安全区 |

## 七、通用原则

以下原则从多个独立研究中反复出现，适用于所有涌现行为：

### 1. 垫脚石机制（Stepping Stones）

- 鬣狗围攻：冒险者 → 安全距离 → 同时攻击 → 围攻
- 通信演化：配偶选择 → 狩猎通信
- Avida EQU：8 个简单逻辑函数 → EQU（19 条指令）
- OpenAI Hide & Seek：6 个阶段策略和反策略
- Avida：某些突变使适应度减半，但为后续 EQU 的出现铺平了道路

### 2. 选择压力必须足够强

- 如果猎物容易抓，捕食者不需要合作
- 如果感染不致命，健康个体不需要避开
- 如果直接感知可行，通信不会演化

### 3. 环境复杂度决定涌现上限

- 最小条件：简单环境 + 简单奖励 → 简单涌现行为（集群、趋化性）
- 最大条件：复杂环境 + 可移动物体 + 物理交互 + 竞争压力 → 复杂涌现行为（工具使用、建筑、分工合作）
- OpenAI Hide & Seek 证明：简单的游戏规则 + 复杂的环境 = 涌现复杂策略

### 4. 多 agent 竞争是自课程机制

- OpenAI Hide & Seek：对手的策略变化自动创建新的学习挑战
- POET：共同进化环境和 agent，无限生成越来越复杂的挑战

### 5. 个体最优 ≠ 群体最优

- Sakana AI 研究表明：个体适应度稳定后，群体适应度可能下降
- 过度优化的个体会减少感知-运动耦合，降低群体多样性

### 6. 环境参数的非线性影响

- 中等噪声、中等视野、低密度 → 促进复杂行为
- 高密度、极端视野 → 鼓励简单线性决策
- JaxLife：256 agent 时通信显著性接近零

### 7. 生态继承的重要性

- 祖先修改的环境必须持久化到后代
- 否则"建筑"行为没有进化意义

### 8. 复杂特征演化可能涉及临时适应度下降

- Avida：EQU 的演化路径中，某些突变使适应度减半
- 但这些"有害"突变为后续复杂特征的出现铺平了道路
