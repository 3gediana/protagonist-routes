# F-COMPARE · 对照实验左右分屏

> 让评委一眼看出某个机制的关键性。

- **难度**：🔴 高
- **确定性档**：🟢 高（功能层面）
- **前置条件**：F-FORK 完美完成
- **状态**：📋 待开发

---

## 一句话

屏幕分成左右两块，分别显示两个独立宇宙（基于 F-FORK），同步滚动。让评委直接对比"有 X 机制 vs 无 X 机制"。

## 你会看到什么效果

> 你说："左边是带'内在动机'的种群，右边是关掉的。看左边发现山顶资源了，右边还在原地打转——这就是好奇心的力量。"

## 实现要点

```
src/runtime/compare/
└── ComparisonRuntime.cpp           同时管理两个 World 实例
```

UI 分屏：
- 左屏：World A
- 右屏：World B
- 中间分隔线
- 共享时间轴
- 共享适应度对比曲线（两条线在同一图）

## 三档完美标准

- MVP：两个世界并行运行能显示
- 完整：性能良好，60 FPS
- 完美：现场演示流畅

## 🧠 补充点

哪些机制值得做对照 —— 你最想证明什么的关键性

## ⚠️ 易踩坑

性能！同时跑两个完整世界 + 两份渲染 = CPU/GPU 双倍负担。**降低单边规模**（如各 50 个 agent）。

## 答辩话术

> "科研中我们说'消融实验'——把某个组件去掉看效果。我把消融实验做成了视觉版。两个种群同样的祖先，只差一个机制，看几代之后差异有多大。"
