# F-NEUROMOD · 神经调节情绪

> 让同一个个体在不同情境下表现得像两只动物。

- **难度**：🟡 中
- **确定性档**：🟡 中（情绪可见性效果不保证戏剧化）
- **前置条件**：M3 完美完成
- **状态**：📋 待开发

---

## 一句话

NEAT 网络中允许特殊"调节神经元"，它们的输出**不参与决策**，而是**改变其它神经元的工作方式**（学习率、激活强度、连接增益）。进化决定哪些情境激活调节神经元 → 看起来像是个体有"情绪"。

---

## 你会看到什么效果

### 完美版
同一个体在饥饿时 → 调节神经元高激活 → 表现激进、冒险、愿意闯陡坡和危险区。
吃饱后 → 调节神经元低激活 → 表现保守、走平地、节能。
**进化没有被告知任何"情绪"概念**，但调节神经元自发对应到了类似情绪的角色。

UI 上每个个体周围有颜色边框：
- 红色 = 调节神经元高激活（"急躁"）
- 蓝色 = 调节神经元低激活（"悠闲"）

### 标准版
调节神经元被进化保留并使用，但角色不一定对应"情绪"那么直观。可能是别的内部状态切换。视觉上仍然有区分，只是讲解时不能简单类比为情绪。

### 降级版
进化压根不用调节神经元（因为简单策略够用了）。**这种情况要老实承认**——这正是 ADR-0002 提到的中确定性风险。
降级方案：把神经调节作为"显式机制"——不是进化决定何时激活，而是直接把"能量水平"映射到一个调节信号，强制注入到网络中。这就不是"涌现的情绪"，而是"人为的情绪机制"，但视觉效果仍然存在。

## 实现要点

### 节点类型扩展

```cpp
enum class NodeType {
    INPUT, HIDDEN, OUTPUT,
    MODULATORY                  // 新增
};
```

### NEAT 变异新增

```
src/core/brain/neat/mutations/
└── AddModulatoryNodeMutation.cpp
```

低概率（默认 1%）add_node 时把新节点设为 MODULATORY 类型。

### 推理时的影响

调节神经元的输出 m_i 不直接影响下游神经元的"激活值"，而是改变下游神经元的"参数"：

```cpp
// 普通神经元 j 的更新
float effective_weight_kj = base_weight_kj * (1 + modulation_factor * m_modulator);
float net_input_j = sum(effective_weight_kj * y_k for all incoming k);
y_j(t+dt) = ctrnn_update(y_j(t), net_input_j, tau_j);
```

调节神经元 m 通过特殊 modulatory connection 影响普通神经元。

### 可视化

```
src/viz/renderer/
└── ModulationOverlay.cpp        在每个 agent 周围画情绪环
```

环颜色由该 agent 当前所有调节神经元的平均激活值决定：
- HSV: H = 0 (红) / 240 (蓝) / 120 (绿) 等，根据激活水平映射
- 透明度可调

### 统计指标

每代记录：
- 种群中含调节神经元的个体比例
- 调节神经元数量随代际趋势
- 调节神经元激活值与"情境特征"（能量水平、附近 agent 数等）的相关性

如果相关性 ≥ 0.3 → 涌现成功
如果接近 0 → 调节神经元在打酱油

## ⚠️ 易踩坑

1. **进化压根不用**：这是最大风险。如果普通策略够用，进化不会保留调节神经元。**用一些"需要情境敏感"的奖励压力**，比如"高能量时优势策略 X，低能量时优势策略 Y"
2. **调节信号过强导致网络不稳定**：modulation_factor 太大可能让网络输出爆炸
3. **可视化误导**：环颜色看起来好看，但如果调节神经元和情境无关，环颜色变化就是欺骗。**必须用相关性指标证明真有用**

## 答辩话术

**完美版**：
> "我没有写情绪系统，只是允许某些神经元起'调节'作用——改变其它神经元的反应强度。进化把这些调节神经元用在了情境敏感的地方：饥饿时激活，强化激进策略；饱腹时安静，让保守策略主导。**情绪不是我编码的，是进化发现的——因为它有用**。"

**降级版（老实讲）**：
> "理想情况下，神经调节神经元应该自发对应情绪。但实验表明，在课设规模下进化没有强烈动机使用这个机制——简单的前馈策略已经能解决基础生存问题。所以我做了一个对比：左边是纯进化版，调节神经元数量很少；右边是显式映射版，把能量水平作为调节信号注入。视觉对比清晰展示了机制的潜力。"
