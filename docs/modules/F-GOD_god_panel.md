# F-GOD · 上帝按钮（实时干预面板）

> 让评委自己点。这是答辩交互王炸。

- **难度**：🟢 低
- **确定性档**：🟢 高（必出）
- **前置条件**：M2 完美完成
- **状态**：📋 待开发

---

## 一句话

UI 上多一个面板，集合所有"对世界做点什么"的按钮：清空食物、投放捕食者、触发地震、改变变异率、抽走 50% 个体……让人现场玩。

---

## 你会看到什么效果

### 完美版
评委盯着大屏幕。你说："你们随便点。"

评委点 [💥 投放捕食者]：
- 屏幕上瞬间出现 5 个红色个体（巨大型，移动快）
- 原种群陷入混乱，散开
- 适应度曲线急速下跌
- 几代后，幸存者中"快速逃跑"基因占优 → 适应度恢复
- 你说："看，进化在面对你刚加的压力时如何重新组织起来。"

评委点 [🌋 地震]：
- 地形被随机重塑
- 个体掉进新形成的山谷
- 几代后种群重新分布
- 你说："种群没有死光，是因为它们的策略具有泛化性。"

### 标准版
按钮工作，干预可见，但效果不一定戏剧化。

### 降级版
不太可能失败 —— 这是纯 UI 模块。

## 实现要点

### 干预接口

```
src/core/intervention/
├── IIntervention.h               所有干预的基接口
└── interventions/
    ├── ClearFoodIntervention.cpp     清空所有食物
    ├── SpawnPredatorIntervention.cpp 投放 N 个捕食者
    ├── EarthquakeIntervention.cpp    重塑部分地形
    ├── PopulationCullIntervention.cpp 随机抽走 X% 个体
    ├── MutationRateChange.cpp        实时改变变异率
    ├── TimeScaleChange.cpp           倍速调整
    ├── FoodFloodIntervention.cpp     大量食物雨
    ├── BarrierIntervention.cpp       立一堵墙
    └── (你想到什么再加)
```

接口：
```cpp
class IIntervention {
public:
    virtual std::string nameKey() const = 0;        // i18n key
    virtual std::string descKey() const = 0;
    virtual void apply(World& world) = 0;
    virtual bool reversible() const { return false; }
    virtual void revert(World& world) {}            // 可逆干预的撤销
};
```

### 干预面板 UI

```
src/viz/ui/
└── GodPanel.cpp
```

按类别分组：
- 🍃 资源类：清空食物 / 食物雨 / 减半再生速率
- 🦴 种群类：抽走 50% / 复活前一代 / 强制变异 / 注入移民
- 🏔️ 环境类：地震 / 立墙 / 改变水位 / 制造火灾
- ⚙️ 元参数：变异率 / 选择压 / 决策周期范围
- ⏱️ 时间类：倍速 / 跳到下一代 / 暂停

每个按钮带：
- 图标
- i18n 名称
- 短描述（hover tooltip）
- 可选数值参数（slider）

### 历史记录与撤销

每次干预记入 `data/runs/<ts>/interventions.jsonl`：
```json
{"tick": 12345, "type": "spawn_predator", "params": {"n": 5}, "user": "demo"}
```

提供 [↶ 撤销] 按钮（仅对可逆干预）。

### 事件广播

干预触发后通过 EventBus 发布 `InterventionTriggered` 事件，让其它观察者（如 F-LLM 解说员）能响应："刚才有人投放了捕食者，让我们看看种群如何应对……"

## ⚠️ 易踩坑

1. **干预破坏统计连续性**：fitness 曲线在干预后断崖式变化，要在曲线上**标注干预点**，避免被误读
2. **干预可能让训练崩溃**：比如"删除所有个体"。**给所有干预加合理性检查**：保留至少 N 个个体
3. **i18n 文案翻译**：12 种干预 × 2 语言 = 24 条文案，写好

## 答辩话术

**演示流程**（5 分钟）：
1. 让世界跑到第 50 代，行为已经稳定
2. 你说："现在让你们当上帝。" 把鼠标递给评委
3. 评委点 [💥 投放捕食者]
4. 你解说：现在原本悠闲的种群感受到压力，看适应度曲线急速下跌
5. 让训练继续 30 代
6. 适应度曲线恢复，但种群行为变了——开始更频繁地往山洞跑
7. 你说：**"我们刚刚目击了一次自然选择。我们没有'告诉'它们去山洞——它们自己发现了"**

这一段几乎能直接拿来当作答辩亮点。
