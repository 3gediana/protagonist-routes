# F-REPLAY · 录制 / 回放系统

> 把整个进化过程录下来，事后任意快放/慢放/拉时间轴。

- **难度**：🟡 中
- **确定性档**：🟢 高
- **前置条件**：M3 完美完成
- **状态**：📋 待开发

---

## 一句话

训练时持续记录所有事件流到磁盘。回放模式下可以加载任意时段的录像，像视频播放器一样拖动进度条、变速。

## 你会看到什么效果

答辩时不需要现场跑训练（耗时几小时不可控），直接加载预录制的"精选片段"——你提前选好的几个关键代际。

## 实现要点

```
src/core/observer/
└── EventRecorder.cpp              订阅所有事件，写入二进制日志

src/runtime/
└── ReplayRuntime.cpp               读取日志，按时间轴重放
```

格式：环形二进制 log + 关键代际的 snapshot（配合 F-FORK）。

回放时不真正跑 core 的 evolution，只重放事件流到 viz。

## 三档完美标准

- MVP：录制 + 基础回放
- 完整：拖动进度条、变速
- 完美：标记"精选时刻"，一键跳转

## 🧠 补充点

- 录制采样频率（高 = 文件大，低 = 不流畅）
- 是否压缩
