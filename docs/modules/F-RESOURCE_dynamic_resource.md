# F-RESOURCE · 资源衰竭与再生

> 食物有"枯竭" / "回血"机制，逼出可持续策略。

- **难度**：🟢 低
- **确定性档**：🟡 中
- **前置条件**：M1 完美完成（升级 ResourceLayer 即可）
- **状态**：📋 待开发

---

## 一句话

食物点不再无限再生。每个食物点有"剩余总量"，被吃完后需要长时间恢复。如果种群"杀鸡取卵"，资源会耗尽。

## 你会看到什么效果

### 完美版
种群分化为"短视贪吃"和"克制觅食"两种策略。短视策略在资源充裕时占优，但资源枯竭后大量饿死；克制策略在低资源期幸存。**公地悲剧的进化版**。

### 标准版
资源动态可见，种群规模波动明显。

## 实现要点

```cpp
struct FoodPoint {
    Vec2 pos;
    float current_amount;       // 当前量
    float max_amount;
    float regen_rate;           // 每 tick 增长
};
```

可视化：食物点大小 = 当前量。

## 三档完美标准

- MVP：资源会被耗尽
- 完整：跑 200 代不让资源彻底死掉
- 完美：观察到种群对资源水平的反馈

## 🧠 补充点

- 食物点数量
- 单个食物点最大量
- 再生速率（决定"杀鸡取卵"还是"涸泽而渔"是否值得）

## 答辩话术
