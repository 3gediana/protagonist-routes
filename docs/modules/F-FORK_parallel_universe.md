# F-FORK · 平行宇宙存档分支

> 把进化变成"可重复实验"。从任意时刻分叉出多个独立宇宙做对照。

- **难度**：🟡 中
- **确定性档**：🟢 高
- **前置条件**：M3 完美完成
- **状态**：📋 待开发

---

## 一句话

任意一代按一下 [💾 存档]，得到这一刻世界的完整快照。从这个快照可以分叉出多个独立"平行宇宙"，分别施加不同条件继续进化，做对照实验。

---

## 你会看到什么效果

### 完美版
你说："我让这个种群在第 50 代时分叉了。左边的宇宙我没动，右边我加倍了食物量。看，30 代后两边走向完全不同的演化路径——左边出现了'蹲守者'，右边因为资源充裕完全没分化出蹲守策略。"

评委："这是你跑两次得到的结果？" 你："不，是同一组祖先在两种环境下平行演化的真实结果。"

### 标准版
存档/读档/分叉功能能跑，但平行宇宙的差异不一定戏剧化。

### 降级版
基本不会失败 —— 这是工程问题，不是涌现问题。

## 实现要点

### 完整快照序列化

```
src/core/snapshot/
├── WorldSnapshot.h / .cpp        所有 layer 状态序列化
├── PopulationSnapshot.cpp        所有 agent + Genome 序列化
└── SnapshotIO.cpp                文件读写（建议二进制 + zstd 压缩）
```

格式：
```
data/snapshots/
└── 2026-05-18_123456_gen50/
    ├── meta.toml                 时间戳、代数、配置摘要
    ├── world.bin                 世界状态二进制
    ├── population.bin            所有 Genome
    └── thumbnail.png             该代的截图
```

### 分叉调度

```
src/runtime/fork/
├── ForkManager.cpp               管理多个并行运行的宇宙
└── ForkConfig.cpp                每个宇宙的配置覆盖
```

可同时运行 2-4 个宇宙（受 CPU 核心数限制，每个宇宙独占一个 EvaluationPool worker）。

### UI

```
src/viz/ui/
└── ForkPanel.cpp
```

- [💾 存档当前]
- [📂 加载存档]
- [🌳 分叉] —— 选一个存档，输入新名字和配置覆盖（如食物量翻倍），新宇宙开始独立运行
- 列表显示所有活跃宇宙，点击切换主显示

### 主显示切换

主屏幕一次只显示一个宇宙。多宇宙运行时左下角小窗口显示其它宇宙的预览缩略图。

完整对照见 F-COMPARE 模块（左右分屏专门对照）。

## ⚠️ 易踩坑

1. **序列化遗漏**：world 的某些状态（如 EventBus 内部状态、随机数发生器状态）容易漏存。**完整恢复测试**：存档 → 立刻读档 → 比较状态完全一致
2. **Genome 序列化**：NEAT 的 innovation_id 全局共享，跨快照恢复时要小心
3. **存档文件膨胀**：500 代 × 100 个体 × 每个 Genome 几 KB = 几 MB/快照。每 100 代存一次合理
