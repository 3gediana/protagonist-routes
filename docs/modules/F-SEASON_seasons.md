# F-SEASON · 季节变化

> 长周期环境变化，逼出迁徙、储能策略。

- **难度**：🟢 低
- **确定性档**：🟡 中
- **前置条件**：F-DAY 完美完成（共用时间系统）
- **状态**：📋 待开发

---

## 一句话

四季循环（每季约 N 代）。冬季食物稀少 + 移动消耗能量更多；夏季食物丰富。个体可以"储存能量"应对冬季。

## 你会看到什么效果

### 完美版
种群进化出"夏天暴吃囤膘"策略。冬天到来时，前期能量储备足的个体存活率更高。某些亚种甚至演化出"冬季迁徙到山洞"。

### 标准版
冬季种群规模缩水但不灭绝。

## 实现要点

```cpp
struct Season {
    enum Type { SPRING, SUMMER, AUTUMN, WINTER };
    Type current() const;
    float resource_factor() const;        // 食物再生倍率
    float metabolism_factor() const;      // 能量消耗倍率
};
```

季节作为感知输入（一个 4 维 one-hot 或 1 维循环值）。

## 三档完美标准

- MVP：季节变化生效
- 完整：种群规模随季节变化但能跨年存活
- 完美：观察到"储能"或"迁徙"等季节适应行为

## 答辩话术

> "短期适应和长期适应是不同的进化压力。昼夜让它们分化出日行夜行；季节让它们分化出储能 vs 散热。"
