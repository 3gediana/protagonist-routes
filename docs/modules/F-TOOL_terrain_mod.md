# F-TOOL · 物种改造地形

> 生物不只是适应环境，它们**改造**环境。挖洞者创造洞穴，筑巢者建造高台。

- **难度**：🟡 中
- **确定性档**：🟢 高
- **前置条件**：M5 地形完成
- **状态**：✅⛳⛳ MVP

---

## 一句话

Agent 的神经网络新增 2 个输出（dig / build），可以实时修改脚下地形高度和洞穴状态，让物种通过改造环境来获得适应性优势。

---

## 你会看到什么效果

### 完美版
"看，这个物种演化出了挖地道策略——它们在低洼处挖出洞穴网络，白天躲在里面避开捕食者，夜间出来觅食。另一个物种则演化出筑巢行为，在高地建造高台获得更好的视野。"

### 标准版
地形确实在代际间被修改，但策略分化不一定戏剧化。

### 降级版
地形修改功能能跑，但能量成本可能太高导致没有物种真正使用它。

---

## 实现要点

### TerrainModifier capability

```
src/core/capability/TerrainModifier.h / .cpp
```

- 2 个输出：dig_intensity [0,1], build_intensity [0,1]
- 3x3 笔刷，高斯权重衰减
- dig 降低高度，build 升高高度
- 深度 dig 自动创建洞穴（高度 < 30% → cave=true）
- 高度 build 自动消除洞穴（高度 > 50% → cave=false）
- 能量成本 = |net_change| × energy_cost_per_unit

### 地形修改的涌现路径

| 策略 | 机制 | 可视化 |
|---|---|---|
| 挖地道者 | 持续 dig → 低洼 + 洞穴 | 热力图暗区 + 洞穴扩展 |
| 筑巢者 | 持续 build → 高台 + 视野 | 热力图亮区 + 高地 |
| 生态工程师 | 两者交替 → 复杂地形 | 地形分形复杂度增加 |

### 与其他模块的关联

- **F-DAY**：夜间挖洞避难，洞穴在夜间提供额外庇护
- **F-DISEASE**：洞穴隔离减少感染传播
- **F-COEVO**：捕食者筑高台获得视野，猎物挖地道躲避
- **F-COOP**：合作筑墙/挖大型洞穴
- **F-HEAT**：热力图叠加地形变化，看空间生态位分化

---

## 配置

```toml
[world.terrain_mod]
enabled = true
dig_rate = 2.0        # 每秒最大高度降低
build_rate = 2.0      # 每秒最大高度升高
energy_cost = 0.5     # 每单位高度变化的能量成本
```
