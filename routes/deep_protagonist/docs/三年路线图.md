# deep_protagonist 三年路线图（毕设 + 冲国一）

> 定位：把"开放世界生存智能体"做成一个**有真问题、有诊断、有结构性修复、可复现、能演示**的项目。
> 三年时间在算力上绰绰有余（并发编排器一周可跑数十组实验）；真正的杠杆是 **新意 / 严谨度 / 呈现**。
> 本文档为主线规划，随进展更新。

---

## 0. 一句话论题（thesis statement）

**共享主干（shared-trunk）PPO+RNN 智能体在开放世界生存任务中的"离散动作退化"问题：诊断、轻量干预与结构性修复。**

根因（已摸到）：网络 `obs → encoder → GRU → {cont_mean, disc_logits, value, successor}`，
连续头（走路）梯度密集、把共享表征带跑了；离散头（吃/喝/打猎/造物等 23 类）在为走路调好的表征上
**专化不出来** → 离散动作熵 ≈ 均匀随机，该吃喝时"乱掷骰子"，早期大量饿死。

   各动作使用分布），并定位到共享主干的梯度干扰。— *已有数据*

   （遵守项目"只增不删"铁律）。这是论文方法层的头牌，用来拉开"单纯调参"的差距。— *待实现（需重编译）*

## 2. 已确立的实证结论（截至 2026-06-23）

### 2.1 survive-first mask：实锤有效，单调剂量反应（对照 = 不带 mask）
| 臂 | eat+drink% | 离散熵% | 饿死/局 | score |
|---|---|---|---|---|
| 对照 ab_ctrl | 13.5 | 85.3 | 76.6 | 0.211 |
| thresh 0.25 | 26.4 | 79.2 | **56.3** | **0.220** |
| thresh 0.35 | 37.1 | 75.5 | 64.6 | 0.212 |
| thresh 0.50 | 46.8 | 66.7 | 62.3 | 0.200 |

- 阈值↑ → 吃喝↑、熵↓ 完美单调；**甜点 0.25–0.35**（0.50 把吃喝顶到最高但 score 反掉，压太狠挤掉别的目标）。
- floor=0：熵掉最猛但 score/reward 双双垫底 → **dead-action-floor 要保留**。
- ent-coef 减半：边际收益小。
- 口径注：analyzer 的"饿死/局"绝对值与早期诊断不同（聚合口径差异），**同口径横比有效**。

### 2.2 并发吞吐实测（选最优 K）
| K | 聚合 eps/min | 卡死臂 | GPU util |
|---|---|---|---|
| 2 | ~27 | 0 | 82% |
| **4** | **48.7** | 0 | 86% |
| 6 | 26.7 | 0 | 88% |
| 8 | 16 | 1 | 88% |
| 12 | 6 | 8 | 89% |

**峰值 K=4**（4臂×8 envs=32 envs=逻辑核数）；>4 被 CPU env 步进抢崩，K=12 反而 ~8× 慢且大量臂卡死。
瓶颈是 **CPU 而非 GPU**（util 全程 86–89%）。→ 正式跑统一用 **K=4 / n_envs=8**。

## 4. 三年里程碑

### 第 1 年 · 打地基（目标：优秀毕设级完整成果）
- 锁定并发编排（K=4）+ 复现性。
- mask 消融多种子跑透 → 贡献 2 完整证据（带置信区间）。
- 实现 **D1 离散头解耦** → 贡献 3，论文头牌结果。
- 记录学习曲线 + 第一支 demo 视频。
- 产出：可复现实验 + 一份完整技术报告初稿。

### 第 2 年 · 做新意（目标：国一差异化）
- 上一个**真正的结构创新**（任选其一深挖）：
  - 分层 / options（时间抽象，治"长程多步生存"）；
  - 内在动机 RND / 计数探索（治探索不足）；
  - world-model / forward-model 辅助损失（提样本效率 + 可视化想象）。
- 逼出**惊艳涌现行为**（天冷自发造衣囤粮过冬等多步策略）。
- 泛化评估 + 更大规模消融。
- 争取憋出一篇 workshop / 会议小论文，给竞赛背书。

### 第 3 年 · 上规模 + 打磨（目标：拿得出手的参赛作品）
- 大规模消融矩阵 + 强基线对比 + 统计显著性。
- 报告成文（方法章节基本由编排器/分析器自动产出，结果由 analyzer 表格+图产出）。
- 打磨 demo 视频 + 海报 + 现场 demo + 答辩反复排练。

## 5. 冲"国一"的杠杆（诚实版）

国一（挑战杯 / 计算机设计大赛 / 互联网+ 这类）= 强竞争 + 评委口味 + 指导老师资源 + 一点运气，**不能保证**。
但本项目原材料好，关键看能否同时做到：
1. **真新意**：至少一条结构/算法层创新（D1 及第 2 年方向），别停在"已知技术拼装"。
2. **惊艳 demo**：会动、有涌现行为的智能体，答辩现场杀伤力极大——这是本项目最大天然优势。
3. **严谨度**：多种子 + CI + 消融 + 强基线 + 泛化。
4. **应用/影响叙事**：往具身智能 / 机器人 / 游戏 AI 引，竞赛吃"有什么用"。
5. **呈现**：视频 + 报告 + 现场 demo + 答辩，能拉开 ~20% 差距。

> 判断：三年纪律性执行下，**强毕设基本囊中之物；国一够得着但不保送**——取决于新意+demo+呈现，而非训练时长。
