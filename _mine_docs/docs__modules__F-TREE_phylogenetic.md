# F-TREE · 物种谱系树

> 把进化的"家谱"画出来。**这是项目最强的视觉震撼之一**。

- **难度**：🟡 中
- **确定性档**：🟢 高（必出，因为 NEAT 物种数据本来就有）
- **前置条件**：M3 完美完成
- **状态**：📋 待开发

---

## 一句话

实时绘制所有曾经存在过的 NEAT 物种的家谱图：何时诞生、何时灭绝、谁是谁的祖先。

---

## 你会看到什么效果

### 完美版
一棵从左（第 1 代）向右（最新一代）生长的树，每个分支是一个物种：
- 分支粗细 = 该物种当前个体数
- 分支颜色 = 该物种平均 fitness（红→绿）
- 分支末端"断裂" = 物种灭绝
- 新分支从父物种长出 = 新物种诞生

可以鼠标 hover 物种 → 显示该物种的代表网络拓扑、生存代际范围、巅峰 fitness、典型行为视频片段。

### 标准版
基础树形图能跑，分支多色，但交互性不强。

### 降级版
列表形式：物种 ID + 出生代 + 死亡代 + 巅峰 fitness。视觉简陋但信息齐全。

## 实现要点

### 数据收集（M3 已经做了一半）

复用 M3 的 `SpeciesObserver` 输出 `species_log.jsonl`：
```json
{"event": "species_born", "id": 7, "parent_id": 3, "gen": 47, "founder_genome": ..., "members": [42, 51, 88]}
{"event": "species_alive", "id": 7, "gen": 48, "size": 4, "avg_fitness": 12.3, "best_fitness": 18.1}
{"event": "species_extinct", "id": 7, "gen": 89, "reason": "no_offspring"}
```

### 树形布局算法

```
src/viz/plot/phylogeny/
├── PhylogenyTree.h / .cpp           树形数据结构
├── TreeLayout.h / .cpp              布局算法（Reingold-Tilford 或简化版）
└── TreeRenderer.cpp                 raylib 绘制
```

布局核心思路：
- X 轴 = 代际（线性）
- Y 轴 = 物种 ID 排布（保证父子物种 Y 接近，避免线条交叉）
- 父子关系用贝塞尔曲线连接

### 交互

- 鼠标 hover → tooltip 显示物种信息
- 鼠标点击 → 跳转到该物种的代表 NEAT 网络拓扑图
- 时间轴拖动 → "时光机"功能，把整个世界状态恢复到选中代

### 实时更新

每代结束 (`GenerationEnded` 事件) 触发增量更新，不重画整棵树。

## ⚠️ 易踩坑

1. **物种 ID 复用**：NEAT 标准实现可能复用灭绝物种的 ID。**禁止复用**，永远递增
2. **树太大**：跑 1000 代后物种数可能上百个，树形图会爆。**做缩放和过滤**：默认只显示存活过 ≥ 5 代的物种
3. **布局抖动**：每次新数据进来重新布局会让整棵树跳动。**用稳定布局**：父物种 Y 坐标固定后不再改
