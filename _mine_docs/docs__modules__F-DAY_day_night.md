# F-DAY · 昼夜循环

> 让世界有"时间"，逼出昼伏夜出策略。

- **难度**：🟢 低
- **确定性档**：🟡 中（行为分化是否明显取决于压力）
- **前置条件**：M5 完美完成
- **状态**：📋 待开发

---

## 一句话

世界状态多一个 `time_of_day` 变量（0-1 循环）。光照影响视野范围；食物再生在白天更频繁；捕食者夜间更活跃；个体能感知当前光照水平。

---

## 你会看到什么效果

### 完美版
种群分化为"日行性"和"夜行性"两类。物种树上能看到这种分化对应的拓扑差异。

### 标准版
个体在不同时段行为有差异，但不一定形成稳定亚种。

---

## 实现要点

```
src/core/world/
└── TimeOfDay.cpp                  全局时间循环
```

```cpp
struct TimeOfDay {
    float t = 0.0f;            // [0, 1)，0 = 午夜，0.5 = 正午
    float light_level() const; // sin 曲线
    float day_length = 600;    // tick
};
```

光照对其它 layer 的影响：
- VisualPerception 的视野半径 = base * light_level
- ResourceLayer 食物再生速率 = base * (light_level + 0.5)
- 视觉渲染：UI 整体调色（白天明亮、夜晚蓝紫）

## 三档完美标准

- MVP：光照变化能跑，UI 颜色随时间变化
- 完整：感知输入接入，跑 100 代不崩
- 完美：种群中观察到时段相关的行为差异

## 🧠 补充点

- 昼夜周期长度
- 光照对视野的影响系数
- 是否做"晨昏"过渡
