# F-CURRICULUM · 课程学习

> 逐级解锁难度，让进化"读完小学再上中学"。

- **难度**：🟡 中
- **确定性档**：🟢 高
- **前置条件**：M3 完美完成
- **状态**：📋 待开发

---

## 一句话

不一开始就把所有挑战都开放给种群。先让它们学会简单任务（趋食），再加难度（出现障碍），再加（出现捕食者），再加（资源稀缺）。**每个阶段满足某个准入条件才进入下一关**。

---

## 你会看到什么效果

种群进步速度比"一次性大乱炖"快很多。能看到清晰的"知识传承"——前期学到的能力作为后期能力的基础。

## 实现要点

```
src/core/curriculum/
├── CurriculumStage.cpp             一个阶段
└── CurriculumScheduler.cpp         检测准入并切换
```

```cpp
struct Stage {
    std::string name;
    std::function<void(World&)> setup;        // 这阶段的世界配置
    std::function<bool(const Stats&)> ready;  // 进入下一阶段的条件
};
```

示例阶段序列：
1. **温室期**（gen 1-30）：地形平坦，食物充裕，无捕食者
2. **生存期**（gen 31-80）：加入地形，资源密度降低
3. **竞争期**（gen 81-150）：加入对抗机制
4. **生态期**（gen 151+）：完整环境

## 三档完美标准

- MVP：阶段切换工作
- 完整：每阶段准入条件合理
- 完美：跑出一份"课程进度报告"，每阶段的种群能力对比

## 🧠 补充点

阶段设计 —— 这是你作为"教师"的设计活

## 答辩话术

> "课程学习是 OpenAI 的论文，但我用它做了进化版——种群不是一次性面对所有压力，而是分阶段成长。看进度图：温室期它们学到趋食，生存期学到避险，到了竞争期已经能应对捕食者。**这是种群级的'童年到成年'**。"
