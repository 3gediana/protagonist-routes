# F-TOOL · 工具与可移动物体

> 让"建筑"涌现成为可能。

- **难度**：🔴 高
- **确定性档**：🔴 低（工具使用涌现是论文级难题）
- **前置条件**：M5 完美完成
- **状态**：📋 待开发

---

## 一句话

地图上散布石头、木棒等可拾取/可放置物体。个体新增 PickUpCapability 和 DropCapability。物体可以被推动、堆叠，可能涌现"用石头堵洞口防御"或"用石头堆高台"等行为。

---

## 你会看到什么效果

### 完美版（🔴 SSR）
某只个体把石头推到山洞口，挡住捕食者进入 → 它的同伴在洞内安全活动。这种"工具防御"被进化保留。

### 标准版
个体偶尔捡起放下物体，但没有有目的的使用。

### 降级版
即使工具使用没涌现，**让物体存在本身让世界更丰富**（多了一种感知输入、多了一层视觉）。

---

## 实现要点

```
src/core/world/layers/object/
├── ObjectLayer.cpp                    可移动物体层
└── PhysicsResolver.cpp                简单刚体（推动、碰撞）

src/core/capability/
├── PickUpCapability.cpp
└── DropCapability.cpp

src/core/perception/
└── NearbyObjectPerception.cpp         感知附近物体的位置和类型
```

物体属性：质量、形状（点 / 圆 / 矩形）、是否可堆叠。

## 三档完美标准

- MVP：物体存在，能拾取和放下
- 完整：物体能被推动，多个物体能堆叠
- 完美：观察到任何"目的性使用"行为

## 🧠 补充点

- 物体类型（石头 / 木棒 / 食物容器）
- 是否允许"组合"（两块石头 → 一堵墙）
- 物体能量消耗（推动重物耗能）

## ⚠️ 易踩坑

物理引擎不要太复杂。**简单网格碰撞 + 推动 = 速度归零**就够，不要做完整刚体。
