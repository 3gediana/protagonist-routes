## 一句话

实现一组进化生态学指标：种群多样性、香农熵、行为复杂度（Lempel-Ziv）、Lyapunov 指数估计、信号-情境互信息（配合 F-COMM）等。在 UI 实时显示。

## 你会看到什么效果

不是行为级的视觉，是**学术级的曲线图**。答辩时这些指标让你的项目从"演示"升级为"实验"。

## 实现要点

```
src/core/observer/stats/
├── ShannonDiversity.cpp          种群基因多样性
├── BehaviorComplexity.cpp        行为序列的 Lempel-Ziv 复杂度
├── LyapunovEstimate.cpp          种群动力学的混沌度
├── MutualInformation.cpp         信号-情境互信息（F-COMM 配合）
└── StatsPanel.cpp                viz 层显示
```

## 三档完美标准

- MVP：至少 3 个指标实时计算
- 完整：UI 显示曲线
- 完美：每个指标的"健康范围"被你界定，能讲清楚现象

## 🧠 补充点

哪些指标对你的论述最有用 —— 这取决于你想证明什么。
